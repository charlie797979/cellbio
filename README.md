# 뉴스클리핑 업무 자동화

## GitHub 저장소에 올릴 파일
- `app.py`
- `requirements.txt`
- `(주)셀바이오휴먼텍 뉴스클리핑 업무파일(10월_한철희).xlsx`

## Streamlit 배포
1. GitHub 저장소에 위 세 파일을 업로드합니다.
2. Streamlit Community Cloud에서 저장소와 `app.py`를 선택해 배포합니다.
3. 앱 설정의 **Secrets**에 아래 항목을 추가합니다.

```toml
GEMINI_API_KEY = "발급받은_무료_Gemini_API_키"
```

4. 앱을 실행하고 업무 엑셀 파일을 업로드하거나 저장소의 템플릿을 사용합니다.
5. `뉴스 검색 및 엑셀 작성`을 누르고 결과를 확인한 뒤 XLSX를 다운로드합니다.

## 주의
- Gemini API 무료 사용량 및 모델 이용 가능 여부는 Google 계정/지역/정책에 따라 달라질 수 있습니다. 유료 모델로 자동 전환하도록 구현하지 않았습니다.
- 뉴스 RSS 검색 결과와 기사 본문 접근은 언론사 사이트 정책 및 네트워크 상태에 따라 누락될 수 있습니다.
- 엑셀 다운로드 후 하이퍼링크를 직접 클릭해 최종 확인하세요.
