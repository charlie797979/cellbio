# 회사 뉴스 클리핑 자동화 앱

## 포함 파일
- `app.py`: Streamlit 앱
- `requirements.txt`: 필요한 파이썬 패키지
- `회사_뉴스클리핑_서식.xlsx`: 회사에서 제공한 원본 서식

## 실행 방법
1. Python 3.10 이상을 설치합니다.
2. 이 폴더에서 터미널/명령 프롬프트를 열고 실행합니다.
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
3. 앱이 열리면 네이버 검색 API의 Client ID와 Client Secret을 입력합니다.
4. `🚀 6개 기업 뉴스 스크랩 및 엑셀 생성` 버튼을 누릅니다.
5. 생성된 엑셀 다운로드 버튼을 눌러 저장합니다.

## API 키 보안
- 네이버 개발자센터에서 검색 API를 신청해야 합니다.
- API 키를 코드에 직접 넣거나 공개 저장소에 올리지 마세요.
- 반복 사용 시 `.streamlit/secrets.toml`을 만들고 다음 형식으로 설정할 수 있습니다.
  ```toml
  NAVER_CLIENT_ID = "본인_Client_ID"
  NAVER_CLIENT_SECRET = "본인_Client_Secret"
  GEMINI_API_KEY = "선택사항_한문장_요약용"
  ```
- `GEMINI_API_KEY`를 입력하면 Gemini가 기사 제목과 설명을 바탕으로 한 문장 요약을 생성합니다. 키가 없으면 네이버 API가 제공하는 기사 설명을 대신 사용합니다. 무료 등급은 이용 한도와 모델 이용 가능 여부가 달라질 수 있습니다.

## 검색/엑셀 동작
- 검색 기간은 버튼을 누른 시점 기준으로 전날 13:00부터 현재 시각까지이며 한국 시간(KST)을 사용합니다.
- 회사 서식의 `월말보고서` 및 다른 탭의 기본 구조와 예시 행을 유지합니다.
- 기업별 탭의 실제 수집 데이터 영역은 이번 실행 결과로 교체됩니다. 이전 실행 결과를 누적하지 않습니다.
- 네이버 검색 API의 조회 한도 때문에 기업별 검색은 최대 1,000건을 조회한 뒤 기간 및 키워드를 필터링합니다.
- 뉴스 검색 API 결과에 포함된 제목/설명에 기업 키워드가 포함된 기사만 기록합니다.
